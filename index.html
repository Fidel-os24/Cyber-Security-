01ABOUT

More than a list of skills.

I’m building my cybersecurity foundation by turning concepts into things I can actually test, document and explain.

My current direction combines Linux, networking, Python and security tooling with practical security projects. Rather than treating cybersecurity as a collection of certificates, I’m using a public project journey to learn by building, breaking, analysing and documenting.

This site is the evidence layer around that journey: what I built, why I built it, what I learned, and where the supporting work can be inspected.
